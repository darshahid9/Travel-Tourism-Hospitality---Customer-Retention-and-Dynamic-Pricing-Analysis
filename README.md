**Hotel Customer Retention & Dynamic Pricing Analysis**
**Project Overview**
This project focuses on building an end-to-end hotel analytics solution using Python, Scikit-Learn, and Power BI.
The objective is to analyze hotel booking data to uncover:

**Cancellation drivers and retention patterns**
Seasonal pricing trends
Customer segmentation behavior
Lead time impact on bookings
Revenue optimization opportunities

**Tech Stack**

Python (Pandas, Scikit-Learn, Matplotlib, Seaborn, Plotly)
Power BI
Jupyter Notebook
GitHub

**Project Structure**

data/ → raw and cleaned datasets
notebooks/ → Jupyter notebooks (cleaning, EDA, ML, dashboard)
src/ → reusable Python functions
reports/figures/ → EDA and model charts
